# candle_shop
Web application development for database management

## main branch currenty up to date with phase 1.5

This project was the assignment for the course of Cloud and Fog Services in spring semester 2022-2023 at Technical University of Crete.

Project had two phases.  
**Phase 1:** Development of web application on localhost  
**Phase 1.5:** Project from phase 1, now running on docker  
**Phase 2:** Docker migration, Microservices integration, GCP migration 

Technologies used:  
* HTML
* CSS
* Javascript
* AJAX
* jQuery
* PHP
* MySQL
* Microservices
* Docker
* REST
* Google Cloud Platform
* Fiware
* MongoDB
* cURL
